# AI feature evaluation

## Procedure
1. Define intended behavior, prohibited behavior, and measurable acceptance criteria.
2. Inspect model, prompt, retrieval sources, data flow, and tool permissions.
3. Build representative, privacy-safe evaluation cases including adversarial cases.
4. Measure quality, grounding, refusal, latency, cost, and fallback behavior.
5. Compare with the approved baseline and report regressions and uncertainty.

## Output
Evaluation version, dataset provenance, results, failure examples, thresholds,
limitations, and release recommendation. Never claim model output is deterministic.
