# Threat modeling

## Procedure
1. Define scope, assets, actors, trust boundaries, and data flows.
2. Enumerate entry points, privileged actions, abuse cases, and dependencies.
3. Rate risks using the project's chosen method and state uncertainty.
4. Map mitigations to owners and verifiable controls.
5. Define security tests, monitoring signals, and residual-risk decisions.

## Output
Scope and flow summary, threats, evidence, severity rationale, mitigations,
verification plan, and accepted/open risks. Do not conduct out-of-scope exploitation.
