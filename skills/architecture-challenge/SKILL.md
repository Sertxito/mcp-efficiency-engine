# Architecture challenge

## Procedure
1. Restate the problem, outcome, constraints, and evidence that motivates the
   proposed design.
2. Test whether each proposed component or migration addresses that evidence.
3. Compare keeping the system, a local fix, a modular boundary, and larger
   alternatives where applicable.
4. Compare complexity, reversibility, migration risk, operations, cost, and
   measurable outcomes.
5. Recommend the smallest experiment or decision record that can resolve
   material uncertainty.

## Output
Counterarguments, simpler options, evidence gaps, trade-offs, and a decision
owner. Challenge ideas without dismissing them by preference.
