# Backlog refinement

## Procedure
1. Start from an approved outcome and source-linked requirements.
2. Split work into independently reviewable vertical slices, not by file, layer,
   or arbitrary size alone.
3. Ensure each item has an outcome, acceptance criteria, dependencies, owner role,
   and validation evidence; flag items missing any of these as not ready.
4. Identify tasks that are blocked, oversized, duplicate, or missing decisions.
5. Present proposed tracker changes for approval before remote synchronization.

## Output
Task proposals with title, rationale, scope, acceptance criteria, dependencies,
owner role, and validation. Do not assign estimates without the team's chosen method.
