# Documentation sync

## Procedure
1. Identify changed behavior and documentation audiences from the diff.
2. Verify claims against source, configuration, and executed checks.
3. Update only affected sections and preserve local conventions and links.
4. Run documentation/link/format checks declared by the project.
5. Mark unresolved discrepancies and unverified behavior explicitly.

## Output
Files/sections updated, source evidence, checks run, and remaining gaps.
Never claim proposed behavior is implemented.
