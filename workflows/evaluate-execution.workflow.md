# Evaluate execution

1. Identify the request, acceptance criteria, execution report, and relevant
   evidence boundary.
2. Compare requested outcomes with observed changes, checks, and unrun work.
3. Apply the matching case and scorecard; keep literal checks separate from
   human semantic judgment.
4. Record failures, unknowns, confidence, and residual risks.
5. Propose bounded follow-ups; require approval before executing state changes.

Do not mark a task complete based only on a success-shaped summary.
