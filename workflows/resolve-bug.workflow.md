# Resolve bug

1. Capture expected and observed behavior, reproduction steps, environment, and
   relevant evidence.
2. Reproduce safely, inspect the smallest affected boundary, and test causal
   hypotheses before changing code.
3. Implement the smallest root-cause fix and add a regression check.
4. Run focused project-declared validation and inspect the resulting diff.
5. Report exact reproduction, source evidence, commands, results, and limits.

Do not mask the symptom, weaken a test, or claim a fix without verification.
