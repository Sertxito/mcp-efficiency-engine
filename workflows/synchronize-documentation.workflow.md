# Synchronize documentation

1. Identify the requested audience and authoritative implementation, contract,
   decision, and validation sources.
2. Compare the affected documentation against those sources and mark drift.
3. Update only claims supported by current evidence; preserve relative links.
4. Validate links, examples, and generated artifacts with repository checks.
5. Report changed documents, remaining discrepancies, and checks run.

Do not silently rewrite historical decisions or state unverified behavior as fact.
