# Modernize legacy

1. Bound business-critical behavior, owners, runtime, deployment, data, and
   compatibility constraints.
2. Reconstruct the current system and baseline behavior from source and tests.
3. Compare retain, stabilize, wrap, replatform, and replace options against
   evidenced goals and risks.
4. Stage any approved change with compatibility, data, cutover, observability,
   and recovery gates.
5. Verify each stage and update decision records and documentation.

Do not assume age implies replacement or treat a plan as migration approval.
