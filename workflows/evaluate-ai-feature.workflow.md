# Evaluate AI feature

1. Bound intended behavior, users, models/versions, grounding sources, tools,
   data classes, evaluation criteria and provider boundaries.
2. Trace prompt/data flows, tool authority, retrieval isolation, output validation,
   failure handling and available telemetry using actual artifacts.
3. Plan representative success, ambiguity, failure and adversarial cases with
   explicit quality, latency and cost criteria or declare exploratory scope.
4. In audit mode report findings only; implement only approved bounded changes.
   Obtain consent before model transfers or tool actions, including evaluation.
5. Run authorized checks and preserve denominators, exact results and failures;
   do not infer correctness from a fluent answer or fabricated benchmark.
6. Document grounding, privacy, authority, fallback and evaluation evidence with
   uncertainty. Observe drift and propose approval-gated learning.

Do not silently export real project data, widen permissions or promote a model.
