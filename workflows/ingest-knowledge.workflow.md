# Ingest knowledge

1. Confirm project initialization, requested sources, access limits, and
   generated-artifact ownership.
2. Inventory source paths and freshness; select supported local processors.
3. Preview scope and exclusions before processing.
4. Normalize and index locally; preserve source path and checksum provenance.
5. Validate source-to-output traceability and report unsupported inputs.

Do not send project content to external services or overwrite unowned artifacts.
Report indexed sources, skipped inputs, outputs, validation, and limitations.
