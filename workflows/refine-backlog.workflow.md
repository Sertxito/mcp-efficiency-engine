# Refine backlog

1. Establish outcome, audience, source evidence, decision owner, and constraints.
2. Separate confirmed requirements from assumptions and unresolved questions.
3. Split work into independently verifiable items with acceptance evidence,
   dependencies, and explicit non-goals.
4. Prioritize using the supplied criteria; do not invent business value.
5. Preview tracker changes and obtain approval for each external write.

Report proposed items, traceability, dependencies, unresolved decisions, and
approval/read-back status.
