name: database-change-example
description: "Example request for a safe SQL Server or NoSQL data change."
---

Assess [SQL Server/Cosmos DB/other store] change [description].

Identify engine/version, schema or partition model, callers, workload, data
sensitivity, and source of truth. Capture the relevant baseline before
recommending performance changes; anonymize sensitive data. Propose a staged,
compatibility-aware change with regression, integrity, monitoring, abort, and
recovery criteria. Separate observed evidence from hypotheses and identify any
production approval still required.
