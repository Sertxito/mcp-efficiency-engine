# Technical debt register

## Capture one item per row
- Stable identifier, category, affected boundary, and source location.
- Verified evidence; mark hypotheses and unknowns explicitly.
- Demonstrated impact, likelihood/urgency rationale, dependencies, and
  confidence.
- Remediation options and effort only where a supported estimate exists.
- Owner, accepted-debt rationale, and review trigger where known.

Do not assign numeric scores or cost-of-delay values without a declared method.
